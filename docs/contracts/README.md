     - Stages: Prospect (Lead) &rarr; Visite Planifiée &rarr; En attente Acompte (48h Relance) &rarr; Confirmé &rarr; En cours &rarr; Terminé.
     - Filtering by delegation (Zone Clustering) and status.

     - One-click tailored messages for visit confirmation, 48-hour deposit countdown, weather rescheduling, and kickoff notification.

     - Direct links to `harvesting_service_contract.html`, `pruning_service_contract.html`, and `proforma_invoice.html` pre-filled with client name, phone, orchard location, tree count, harvest quantity, and calculated pricing.
